## 👨‍💻 About Me

I'm a cybersecurity student building a strong foundation in security
concepts, operating systems, networking, and practical security testing.
I'm interested in understanding how systems fail, how vulnerabilities
can be identified responsibly, and how organizations can detect and
respond to threats.

I'm exploring both **offensive security** and **defensive
security**---from web application testing and penetration-testing labs
to security monitoring, log analysis, and incident response.

-   🔐 **Interests:** Ethical hacking, web security, vulnerability
    assessment, SOC operations, and digital forensics.
-   🐧 **Learning environment:** Linux and security-focused lab
    environments.
-   🧪 **Practice:** Hands-on exercises, CTF challenges, and personal
    labs.
-   📝 **Approach:** Learn the fundamentals, document the process, and
    improve through practice.
-   🤝 **Goal:** Find an opportunity to learn from experienced security
    professionals and contribute to a security team.

> I believe good security work is not just finding a weakness---it's
> understanding the risk, documenting evidence clearly, and helping make
> systems safer.
